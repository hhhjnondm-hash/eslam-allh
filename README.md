# إسلاميات | رفيق كل مسلم

## 🌟 عن المشروع

موقع إسلاميات هو موقع إسلامي شامل يقدم لك:
- 📖 **القرآن الكريم** - سور من القرآن الكريم مع التلاوات
- 🕌 **أوقات الصلاة** - مواقيت الصلاة اليومية الدقيقة
- 🎧 **مصاحف صوتية** - استماع إلى القرآن الكريم بصوت أشهر القراء
- 📻 **راديو** - إذاعات القرآن الكريم المتعددة
- 📚 **مقالات وقراءات** - محتوى إسلامي مفيد
- 📿 **الأذكار** - أذكار الصباح والمساء وبعد الصلاة
- 📖 **أحاديث نبوية** - أحاديث شريفة مختارة
- ❓ **أسئلة وأجوبة** - إجابات على أسئلة دينية
- 💝 **آيات قرآنية** - آيات مختارة للتأمل
- 🎁 **صندوق رفيق** - محتوى إسلامي متنوع

## 🚀 المميزات

### 📱 Responsive Design
- متجاوب مع جميع أحجام الشاشات (320px إلى 2560px+)
- دعم كامل للموبايل والتابلت والديسك توب
- متوافق مع Telegram Mini App
- دعم شاشات iPhone مع Safe Areas

### 🎨 التصميم
- تصميم عربي إسلامي أنيق
- تأثيرات بصرية متحركة
- وضع ليلي/نهاري
- تجربة مستخدم سلسة

### 🔧 التقنيات المستخدمة
- HTML5, CSS3, JavaScript
- Bootstrap 5
- FontAwesome Icons
- Google Fonts (Cairo, Changa, Tajawal)
- Aladhan API لأوقات الصلاة

## 🛠️ التثبيت والتشغيل

### الطريقة المباشرة:
1. قم بتحميل الملفات من المستودع
2. افتح `index.html` في المتصفح
3. استمتع بتصفح الموقع

### باستخدام خادم محلي:
```bash
# باستخدام Python
python -m http.server 8080

# باستخدام Node.js
npx http-server -p 8080

# باستخدام PHP
php -S localhost:8080
```
